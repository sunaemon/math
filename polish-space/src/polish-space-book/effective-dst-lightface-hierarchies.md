# Effective DST: Lightface Hierarchies {#sec:effective-dst}

<!-- formalization: skip-begin (chapter motivation, proof scope, and roadmap) -->

The classical theory developed in the preceding sections is **\termforwardas{boldface class}{boldface}**: open, Borel,
analytic, and projective classes are defined topologically, with no constraint on the complexity of the data defining
them. **\termdefineas{effective descriptive set theory}{Effective descriptive set theory}** is the
**\termforwardas{lightface class}{lightface}** counterpart, in which classes are defined by *recursive* (i.e.,
computable) predicates and parameters from $\R$ are eliminated. The two theories run in tandem — classical results
acquire sharp computability-theoretic refinements — and the bridge between them is the technical prerequisite for the
classification and computability chapters that follow.

<!-- formalization: skip-end -->

The passage from boldface to lightface mirrors the passage from arbitrary open subsets of Baire space to recursively
enumerable lists of cylinders. Topologically, an open set is a union of basic cylinders:
$$U = \bigcup_{s \in A}\cyl{s} \qquad (A \IncludedIn \finseq{\omega}).$$
$U$ is effectively open when it has such an enumeration of cylinders generated by a lambda program. The lambda-calculus
appendix fixes the indexing convention; here we use it to put an algorithmic constraint on every construction.

The first lightface classes can be described in terms of effective tests on names. For an effectively open set,
membership is witnessed by a cylinder already seen in an enumeration. For an effectively closed set, nonmembership is
witnessed by a forbidden finite prefix. For an effectively analytic set, membership is witnessed by an infinite sequence
whose finite approximations pass all recursive tests. In this last case, the witness need not be finite or computable.

## The Effective Framework {#sec:edst-core-dichotomies}

The classification results in §{sec:borel-reducibility} need more than the vocabulary of lightface pointclasses. Silver
and HKL require a core of effective descriptive set theory whose pieces fit together in a fixed order:

1.  recursive trees and projections, so analytic and coanalytic statements become questions about branches and
    well-foundedness;
2.  ordinal notations and recursive well-orders, so well-founded trees have ranks that can be compared effectively;
3.  coanalytic norms, so a $\lPi^1_1$ set is approximated by Borel initial segments;
4.  effective boundedness, so lightface analytic families of codes for recursive well-founded trees have a
    common recursive ordinal bound on their ranks;
5.  basis and separation theorems, so rank bounds produce definable witnesses and Borel separators;
6.  the Gandy--Harrington topology, so analytic sets can be treated as basic open neighborhoods during fusion;
7.  the actual dichotomy arguments, where the preceding infrastructure prevents the fusion from collapsing.

The book splits this material across three chapters. This chapter develops items 1 and 2: the lightface hierarchy,
recursive trees, universal sets, and ordinal notations. §{sec:effective-dst-ranks} develops items 3 through 5,
together with recursive Borel codes and effective versions of classical theorems.
§{sec:effective-dst-dichotomies}
develops items 6 and 7: the Gandy--Harrington topology, Silver's dichotomy, and the HKL embedding theorem.

Both proofs are carried out in §{sec:effective-dst-dichotomies}. Silver uses generic-pair splitting and a
perfect-antichain
fusion with retained analytic witnesses. HKL additionally constructs the nonsmooth kernel, proves invariant
separation, and refines relations on finite trees to encode eventual equality.

### Computations with a fixed real parameter {#sec:edst-relative-programs}

\begin{mathmeta}
  \vars{s}{Seq}
  \vars{\varepsilon}{Name}
\end{mathmeta}

Throughout the effective arguments, a program is a finite lambda term. Fix a real parameter
$\varepsilon:\NN\to\NN$ and a numerical coding of the inputs. A program may query $\varepsilon(n)$ while
performing beta reduction, as defined in §{sec:lambda-input-realizers}. A predicate on the coded inputs is
\emph{decidable relative to $\varepsilon$} when one closed term terminates on every valid input code and returns
one if the predicate holds and zero otherwise. The parameter is fixed throughout the computation and throughout
any argument using the same relative pointclass. No behavior is prescribed on numbers that are not valid input
codes. The lambda terms and their numerical indices are described in §{sec:lambda-syntax-codes}.

\begin{proposition*}[\termdefineas{Countability of relative predicates}{Countability of relative predicates}]
For a fixed parameter and fixed numerical codings, there are only countably many relatively computable total
functions and relatively decidable predicates.
\end{proposition*}

\begin{proof}[Proof]
Every closed lambda term has a natural-number syntax index. With the parameter fixed, uniqueness of numerical
outputs implies that one index computes at most one function on the specified input set, and decides at most
one predicate there. Choose one index for each function or predicate. Equal chosen indices imply equal values
on every input, so this assignment is injective into $\NN$. This proves countability; it does not give an algorithm
for recognizing the indices that terminate on all valid inputs.
\end{proof}

\begin{proposition*}[\termdefineas{A common parameter for countably many predicates}{A common parameter for countably
many predicates}]
Let $S$ have a fixed injective numerical coding $c:S\to\NN$. For any sequence of predicates $R_i$ on $S$, there is
one real parameter relative to which every $R_i$ is decidable.
\end{proposition*}

\begin{proof}[Proof]
Use the numerical pairing of §{sec:lambda-numerical-pairing}. For each $z\in S$, give the parameter value one
at the pair of $i$ and $c(z)$ exactly when $R_i(z)$ holds, and zero at every other coordinate.
Injectivity of the coding makes this definition unambiguous. For fixed $i$, a closed program pairs the numeral
for $i$ with the supplied input code,
queries that coordinate, and returns the answer. Numerical pairing is computed by a closed lambda term, so this
is an actual program using the chosen parameter. The construction puts all the predicates' truth values into
that parameter; it does not assert that the parameter itself is computable. The explicit row-reading term is
given in §{sec:lambda-relative-predicates}.
\end{proof}

For a predicate on coded inputs, call a computation \emph{accepting} when it returns the numeral one.
A predicate is \emph{semidecidable relative to $\varepsilon$} if a closed program accepts exactly its members.
Other outputs count as rejection. This gives the same predicates as requiring a program to have a numerical
output exactly on the members: search the finite computation certificates and return one only after a successful
test. The two directions, including exclusion of numerical outputs when no test succeeds, are proved in
§{sec:lambda-total-enumerations}. Thus an effectively open set relative to $\varepsilon$ may be specified by a
semidecidable family $W$ of finite words and the union $\bigcup_{s\in W}\cyl{s}$. Its complement is effectively closed
relative to the same parameter.

\begin{proposition*}[\termdefineas{Total enumeration of a nonempty semidecidable family}{Total enumeration of a
nonempty semidecidable family}]
Fix $\varepsilon$. Every nonempty family $W$ of finite words that is semidecidable relative to $\varepsilon$
has a total lambda-computable enumeration relative to $\varepsilon$ whose range is exactly $W$.
\end{proposition*}

\begin{proof}[Proof]
Choose $s_\ast\in W$ and an index for its accepting program. Decode the stage as a pair $\Pair{a}{r}$, where $a$ is a
word code and $r$ bounds a finite search for a computation returning one on that code. Run the total certificate
test with parameter $\varepsilon$. If it succeeds, output the word coded by $a$; otherwise output $s_\ast$.
The explicit lambda programs for the test and selection are given in §{sec:lambda-total-enumerations}.
Each stage terminates even when the original accepting computation does not. Soundness of the certificate test
ensures that every output belongs to $W$. Conversely, every word in $W$ has a finite accepting computation,
so some bound certifies it and a stage with that word code outputs it. This proves equality of the range.
The chosen member is fixed data in the program; this argument does not decide whether a given family is empty.
\end{proof}

## Recursive Trees and Projections {#sec:edst-recursive-trees}

\begin{mathmeta}
  \vars{i,n}{Nat}
  \vars{a,u}{Seq}
  \vars{b,s,t}{Seq}
  \vars{p,q}{Name}
  \vars{s_*}{Seq}
  \vars{a_*,b_*}{Nat}
\end{mathmeta}

The basic coding object is a \termdefine{recursive tree}: a tree $T\IncludedIn\finseq{\omega}$ whose membership relation
on finite sequences is decidable by a program.

A tree is closed under initial segments, so $t\in T$ and $s\prefixOf t$ imply $s\in T$.

Its body
$$
[T]:=\{p\in\BaireSpace:\restrict{p}{n}\in T\text{ for all }n\}
$$
records its infinite branches.

\begin{lemma*}[Stage-cutoff tree identity]
For any sequence $\Sequence{s_i}{i\in\omega}$ of finite words, put
$$
T:=\{t\in\finseq{\omega}:\text{no }s_i\text{ with }i\le \Length{t}\text{ is a prefix of }t\}.
$$
Then $T$ is a tree and
$$
[T]=\SetDifference{\BaireSpace}{\bigcup_{i\in\omega}\cyl{s_i}}.
$$
\end{lemma*}

\begin{proof}[Proof]
The definition is downward closed: if $u\prefixOf t$ and $s_i\prefixOf u$ with $i\le\Length{u}$, then $s_i\prefixOf t$
and
$i\le\Length{t}$. If $s_i\prefixOf p$, then $\restrict{p}{n}\notin T$ once $n\ge\max\{i,\Length{s_i}\}$. Conversely, if
$\restrict{p}{n}\notin T$, some $s_i$ with $i\le n$ is a prefix of $\restrict{p}{n}$ and hence of $p$. These two
implications give the displayed identity.
\end{proof}

\begin{proposition*}[\termdefineas{Lambda decision of the stage-cutoff tree}{Lambda decision of the stage-cutoff tree}]
If a closed numerical lambda term computes the codes of the words $s_i$ from $i$, then the stage-cutoff tree
above has a closed numerical lambda membership decider. Its body is the complement of the union of the
forbidden cylinders, as in the preceding lemma.
\end{proposition*}

\begin{proof}[Proof]
On the code of $t$, compute $\Length{t}$. For each $i\le\Length{t}$, compute the code of $s_i$ and test whether $s_i$ is
a prefix
of $t$. This test compares the code of $s_i$ with the code of the first $\Length{s_i}$ entries of $t$; if $s_i$ is
longer
than $t$, the codes differ. Prefix extraction and numerical equality are computed by closed terms in
§{sec:lambda-prefix-margin-programs}. Let $a_i$ be zero when the prefix test succeeds and one otherwise. Starting
with $b_0=1$, use numerical primitive recursion to compute $b_{i+1}=b_i a_i$ through stage $\Length{t}+1$. Every test
terminates, so the bounded recursion terminates. The output is one exactly when none of the forbidden words
with index at most $\Length{t}$ is a prefix of $t$, which is exactly membership in the stage-cutoff tree. It is zero
otherwise. Pairing, composition, and the recursor combine these operations into one closed term. The tree and
body assertions are those of the preceding lemma.
\end{proof}

With a real parameter fixed, recursive trees form a countable family: send each tree to its decidable membership
predicate and apply §{sec:edst-relative-programs}. The preceding numerical decider also works relative to any
parameter, since it makes no queries to that parameter.

\begin{proposition*}[\termdefineas{Relative decision of the stage-cutoff tree}{Relative decision of the
stage-cutoff tree}]
Fix a real parameter $\varepsilon$. If one closed lambda program, using $\varepsilon$, computes the code of $s_i$
for every $i$, then the stage-cutoff tree is decidable relative to $\varepsilon$. Its body is again
$\SetDifference{\BaireSpace}{\bigcup_i\cyl{s_i}}$. No termination assumption for other parameters is needed.
\end{proposition*}

\begin{proof}[Proof]
Use the preceding prefix test, passing the same input variable to the enumeration program at every stage.
For a word $t$, exactly $\Length{t}+1$ tests are required. Each terminates with the fixed parameter, and the
input-query recursor multiplies their zero/one answers. The construction in §{sec:lambda-prefix-margin-programs}
proves this finite recursion directly by beta/query reduction and gives a closed program, uniformly in the
code of $t$. The output is one precisely when no forbidden word with index at most $\Length{t}$ is a prefix of $t$.
The stage-cutoff identity supplies downward closure and the asserted body.
\end{proof}

\begin{theorem*}[Effective closed-set tree representation]
A set $F\IncludedIn\BaireSpace$ is effectively closed if and only if $F=[T]$ for a recursive tree
$T\IncludedIn\finseq{\omega}$. The same equivalence holds relative to any fixed real parameter.
\end{theorem*}

\begin{proof}[Proof]
Work with one fixed parameter throughout. If membership in $T$ is decidable, its complement is decidable and
hence semidecidable. The cylinders $\cyl{s}$ for $s\notin T$ have union exactly the complement of $[T]$,
so $[T]$ is effectively closed relative to that parameter.

Conversely, write the complement of $F$ as the union of cylinders from a semidecidable family $W$.
If $W$ is empty, $F=\BaireSpace$ and the full tree has the required body; its constant-one decider makes no queries.
If $W$ is nonempty, the preceding total-enumeration proposition supplies a sequence $s_0,s_1,\ldots$ with range $W$.
Apply the relative stage-cutoff construction: membership is decided by the first $\Length{t}+1$ prefix tests, with each
zero-or-one answer complemented,
and its body is the complement of exactly those cylinders. Thus $F=[T]$.
For the parameter-free case use the constant-zero parameter. Substituting the closed constant-zero term in each
total enumerator or decider produces ordinary beta computations, as §{sec:lambda-total-enumerations} explains.
\end{proof}

For analytic sets one uses trees on pairs of finite sequences. A tree on pairs is a set
$T\IncludedIn\finseq{\omega}\times\finseq{\omega}$ such that $\Pair{s}{t}\in T$ implies $\Length{s}=\Length{t}$ and
$\Pair{\restrict{s}{n}}{\restrict{t}{n}}\in T$ for every $n$. It is recursive relative to a fixed parameter
$\varepsilon$ if a closed lambda program decides membership on the code
$\NatPair{\LambdaListCode{s}}{\LambdaListCode{t}}$. Its body and projection are
$$\begin{aligned}
[T]&=\{\Pair{p}{q}:\Pair{\restrict{p}{n}}{\restrict{q}{n}}\in T\text{ for all }n\},\\
\pi_0([T])&=\{p:\exists q\ \Pair{p}{q}\in[T]\}.
\end{aligned}$$

\begin{proposition*}[Operations on relative pair trees]
Fix $\varepsilon$. The trees recursive relative to $\varepsilon$ form a countable family, their bodies are closed,
and their projections are analytic. Their projections are closed under finite intersections and include every
cylinder. If $T$ is such a tree and $a,b$ are finite words, there is another such tree with body
$[T]\cap(\cyl{a}\times\cyl{b})$.
\end{proposition*}

\begin{proof}[Proof]
A membership decider determines its tree uniquely, so countability follows from the countability of relative
predicates. For each length, the allowed prefix pairs give a clopen condition on the two infinite sequences.
Intersecting these conditions gives the closed body; its continuous projection is analytic. For two trees $T,S$,
write $u_1,u_2$ for the words obtained by applying the two numerical projections to every entry of $u$, and put
$$R=\{\Pair{s}{u}:\Pair{s}{u_1}\in T\text{ and }\Pair{s}{u_2}\in S\}.$$
The list-map and numerical-pairing terms compute the two membership inputs, and multiplication combines the two
zero/one answers. Word projection commutes with truncation, so this is a synchronized downward-closed tree.
A branch through $R$ gives two witnesses. Conversely, witnesses $q,r$ for the same point are combined into the
sequence $\Sequence{\NatPair{q(n)}{r(n)}}{n\in\omega}$. Hence $\pi_0([R])=\pi_0([T])\cap\pi_0([S])$.
The full tree consists of all pairs of equal length; equality of the computed lengths decides membership.
Its projection is the whole space, which also handles the empty intersection.

For the cylinder restriction, retain those $\Pair{s}{t}\in T$ for which $s,a$ are comparable by the prefix relation,
and likewise $t,b$. Both comparisons are decidable by finite-list prefix tests. Comparability is preserved by
truncating the variable word. An infinite sequence has every prefix comparable with $a$ exactly when it extends
$a$: test the prefix of length $\Length{a}$ for the nontrivial implication. Thus the restricted body is exactly
$[T]\cap(\cyl{a}\times\cyl{b})$. Apply this to the full tree with $b$ empty to obtain the cylinder $\cyl{a}$ as a
projection. The explicit programs are given in §{sec:lambda-pair-tree-programs}.
\end{proof}

The correspondence between existential-real arithmetic formulas and relative pair-tree projections is proved
in §{sec:edst-arithmetic-normal-form}. The proof keeps the same real parameter and allows any finite number
of natural-number quantifiers.

Coanalytic sets are complements of such projections, so they are well-foundedness conditions.

Given a recursive tree $T$ on pairs, define for each $p$ the section tree
$$
T_p:=\{t\in\finseq{\omega}:\Pair{\restrict{p}{\Length{t}}}{t}\in T\}.
$$

\begin{proposition*}[Relative computation of a section tree]
If $T$ is recursive relative to $\varepsilon$, then $T_p$ is a prefix tree recursive relative to
$\delta(n)=\NatPair{\varepsilon(n)}{p(n)}$.
\end{proposition*}

\begin{proof}[Proof]
From a finite word $t$, compute its length, read the first $\Length{t}$ values of $p$, and form the pair of list codes
for $\Pair{\restrict{p}{\Length{t}}}{t}$. Feed this pair into the decider for $T$. Each query to $\varepsilon$ and each
query to
$p$ is answered by the corresponding numerical projection of a query to $\delta$. Only finitely many values of
$p$ are needed for each input, and the decider terminates relative to the fixed $\varepsilon$.
Truncating the pair shows that $T_p$ is downward closed. This construction uses both inputs; it does not assert
that an arbitrary section is recursive relative to $\varepsilon$ alone.
\end{proof}

\begin{lemma*}[Pair-tree section test]
For every $p\in\BaireSpace$,
$$
p\notin \pi_0([T])
\quad\Longleftrightarrow\quad
T_p\text{ is well-founded}.
$$
\end{lemma*}

\begin{proof}[Proof]
A branch $q$ through $T_p$ is exactly a witness satisfying
$\Pair{\restrict{p}{n}}{\restrict{q}{n}}\in T$ for every $n$. Negating the existence of such a branch gives the
equivalence.
\end{proof}

<!-- formalization: skip (application guidance for the rank machinery in the next chapter) -->
This translation is the workhorse. A $\lPi^1_1$ assertion about $p$ becomes the assertion that an effectively given tree
$T_p$ has no infinite branch. Once that happens, ranks enter automatically: if $T_p$ is well-founded, its rank measures
how hard it is to verify the absence of a branch.

<!-- formalization: skip (computability and pointclass-completeness assertions; the underlying tree identities are
formalized above) -->

Two warnings keep the coding honest. First, a recursive tree may have paths without computable paths, so nonemptiness of
$[T]$ is not an effective existence theorem. Second, well-foundedness is not decidable from the recursive code of $T$.
It is $\lPi^1_1$-complete, as §{sec:edst-boundedness} proves. Effective DST is powerful precisely because it controls
the ranks of well-founded trees without pretending that well-foundedness is computable.

### Finite tests and coordinatewise inverse images {#sec:edst-finite-check-trees}

\begin{mathmeta}
  \vars{j}{Nat}
  \vars{f}{Fun(Nat,Nat)}
  \vars{\widehat{f}}{Fun(Name,Name)}
\end{mathmeta}

\begin{proposition*}[\termdefineas{finite-test tree construction}{Trees defined by finite tests}]
Fix a parameter $\varepsilon$. Let $R_i(s,t)$ be a predicate decided by one closed lambda program,
uniformly in $i,s,t$, relative to $\varepsilon$. Define
$$S_i=\{\Pair{s}{t}:\Length{s}=\Length{t},\quad\forall j\le\Length{s}\ R_i(\restrict{s}{j},\restrict{t}{j})\}.$$
Then the $S_i$ are relative pair trees with jointly decidable membership, and
$$\begin{aligned}
[S_i]&=\{\Pair{p}{q}:\forall j\ R_i(\restrict{p}{j},\restrict{q}{j})\},\\
\pi_0([S_i])&=\{p:\exists q\ \forall j\ R_i(\restrict{p}{j},\restrict{q}{j})\}.
\end{aligned}$$
No closure condition on $R_i$ is required.
\end{proposition*}

\begin{proof}[Proof]
Compute the two lengths and, for each $j\le\Length{s}$, extract the two prefixes and apply the supplied decider
with the same index and parameter. Multiply these decision bits and the length-equality bit. List truncation
and the relative bounded-product term make this one terminating program, as detailed in
§{sec:lambda-kleene-brouwer}. If a node is truncated to length $m$, each subsequent prefix test is a
test at length $\min(j,m)$ already required at the original node. Thus the accepted nodes form a tree.
A branch satisfies the test at length $j$ by applying the node condition to its length-$j$ prefix.
Conversely, if all branch tests hold, every test on every prefix holds. This proves the body identity;
existentially quantifying the second coordinate gives the projection identity.
\end{proof}

The test at length zero is included: if $R_i(\varnothing,\varnothing)$ fails, $S_i$ is empty.
If $R_i$ is already membership in a synchronized downward-closed tree, the construction preserves every node.
These facts distinguish this construction from the delayed-rejection trees of §{sec:edst-pair-tree-indices},
which always contain the empty node and need preserve only bodies and projections.

\begin{proposition*}[\termdefineas{coordinatewise inverse image}{Coordinatewise inverse images of tree projections}]
Let $f:\NN\to\NN$ be a total function computed by a closed numerical lambda term, and write
$\widehat{f}(p)=f\circ p$. If $T$ is a pair tree recursive relative to $\varepsilon$, put
$$S=\{\Pair{s}{t}:\Pair{\operatorname{map}(f,s)}{t}\in T\}.$$
Then $S$ is a pair tree recursive relative to the same parameter, and
$$\begin{aligned}
[S]&=\{\Pair{p}{q}:\Pair{\widehat{f}(p)}{q}\in[T]\},\\
\pi_0([S])&=\widehat{f}^{-1}(\pi_0([T])).
\end{aligned}$$
\end{proposition*}

\begin{proof}[Proof]
Apply the list-map term to the code of $s$, retain the code of $t$, pair the results, and run the decider for
$T$. Totality of $f$ gives termination on every finite word. Mapping preserves length and commutes with
truncation, so synchronization and downward closure follow from those of $T$. For every infinite sequence,
mapping its length-$n$ prefix gives the length-$n$ prefix of its image. Applying this identity at every
length proves the body equality. The witness $q$ is unchanged in both directions, giving the projection
equality. This proves closure for coordinatewise maps. The construction in §{sec:edst-computable-preimages}
extends it to arbitrary total computable maps between Baire spaces.
\end{proof}

### Coordinate projections and relational images {#sec:edst-coordinate-projections}

\begin{mathmeta}
  \forward{NamePair,NameProjection}
  \define{WordPair}
  \vars{p,q,u,x,y}{Name}
\end{mathmeta}
For sequences, use pointwise numerical pairing
$\NamePair{p}{q}(n)=\NatPair{p(n)}{q(n)}$, and let $\NameProjection{1}{u}$ and
$\NameProjection{2}{u}$ apply the two numerical inverse projections to every entry of $u$.
They recover $p,q$ from their pair, and pairing the two projections recovers $u$.
For finite words, $\WordPair{s}{t}$ has length $\Length{s}$ and pairs their entries in order, using zero for
an entry of $t$ beyond its length. On equal-length words, no default is needed. Pairing and both
projections commute with taking equal-length prefixes.

\begin{proposition*}[\termdefineas{relative coordinate projection}{Coordinate projection of a relative tree}]
Let $T$ be a pair tree recursive relative to $\varepsilon$. There is a pair tree $S$ recursive relative
to the same parameter such that
$$\begin{aligned}
[S]&=\{\Pair{x}{u}:\Pair{\NamePair{\NameProjection{1}{u}}{x}}{\NameProjection{2}{u}}\in[T]\},\\
\pi_0([S])&=\{\NameProjection{2}{p}:p\in\pi_0([T])\}.
\end{aligned}$$
Thus existential quantification over either coordinate of a coded pair preserves relative pair-tree presentations.
\end{proposition*}

\begin{proof}[Proof]
For a finite word $v$, write $v_1,v_2$ for its entrywise projections. Use the finite test
$$R(s,v)\quad\Longleftrightarrow\quad\Pair{\WordPair{v_1}{s}}{v_2}\in T.$$
List mapping computes $v_1,v_2$; the finite-tabulation program in §{sec:lambda-projection-programs}
computes the paired word. Hence this test is decidable relative to $\varepsilon$. Apply the finite-test
construction of §{sec:edst-finite-check-trees} to obtain $S$, including the test at length zero.
Its body consists exactly of the pairs satisfying every prefix test. Commutation with prefixes gives
the displayed body identity.

A witness $u$ for $x\in\pi_0([S])$ gives the point $\NamePair{\NameProjection{1}{u}}{x}$ in
$\pi_0([T])$, with witness $\NameProjection{2}{u}$. Conversely, if $\Pair{p}{q}\in[T]$, use
$u=\NamePair{\NameProjection{1}{p}}{q}$ as the witness for $\NameProjection{2}{p}$ in the new tree.
The inverse identities for pairing prove both assertions. To omit the other coordinate, first swap the
two point coordinates. The swap is computed entrywise by the numerical projections and pairing, so
§{sec:edst-finite-check-trees} supplies its inverse image before applying the construction just proved.
No new parameter and no decision procedure for the projected set are required.
\end{proof}

\begin{corollary*}[\termdefineas{relative relational image}{Relational images at a fixed parameter}]
Suppose $A$ and the coded relation $\{\NamePair{x}{y}:R(x,y)\}$ have pair-tree presentations recursive
relative to the same $\varepsilon$. Then so does
$$\{y:\exists x\in A\ R(x,y)\}.$$
\end{corollary*}

\begin{proof}[Proof]
Take the inverse image of $A$ under the first coordinate projection, intersect it with the coded relation,
and then project to the second coordinate. These three constructions all preserve the fixed parameter.
A point in the resulting image supplies $x\in A$ and $R(x,y)$; conversely such an $x$ gives the coded point
$\NamePair{x}{y}$ in the intersection. For an equivalence relation, this is the construction of its
saturation of $A$.
\end{proof}

### Computable inverse images {#sec:edst-computable-preimages}

\begin{mathmeta}
  \vars{x,y}{Name}
  \vars{m,n,r}{Nat}
  \vars{i}{Nat}
  \define{ZeroExtendedWord}
  \vars{F}{Fun(Name,Name)}
\end{mathmeta}

\begin{proposition*}[\termdefineas{computable inverse image of relative projections}{Computable
inverse images at a fixed parameter}]
Fix $\varepsilon$. Suppose one closed lambda program computes every coordinate of a total map
$F:\BaireSpace\to\BaireSpace$ from the paired input $\NamePair{\varepsilon}{x}$.
If $A$ has a pair-tree presentation recursive relative to $\varepsilon$, so does $F^{-1}(A)$.
\end{proposition*}

\begin{proof}[Proof]
Let $e$ be the index of the supplied program. First construct a tree presentation of the coded graph
$G_F:=\{\NamePair{x}{y}:y=F(x)\}$. A row $i=\NatPair{n}{\NatPair{m}{r}}$ proposes output $m$ at
coordinate $n$ and tests all computation certificates below stage $r$.
The list coding gives a useful bound: every address checked at stage $r$ is less than $r$,
as proved in §{sec:lambda-stage-address-bound}. Both $n$ and $r$ are at most $i$.
For a finite word $t$, let $\ZeroExtendedWord{t}$ denote its extension by zeros to an infinite sequence.
For a prefix $s$ of the coded point, extend each of its coordinate projections in this way.
Run the stage-$r$ test with input $\NamePair{\varepsilon}{\ZeroExtendedWord{s_1}}$;
if it certifies output $m$ at coordinate $n$, require $s_2(n)=m$.
For this row use exactly the prefix of length $i+1$. The test is finite and decidable relative to
$\varepsilon$ by the explicit program in §{sec:lambda-graph-tests}.

At length $N$, test every row $i<N$ on the prefix of length $i+1$, and impose these tests at all
shorter prefixes as in §{sec:edst-finite-check-trees}. The stage bound ensures that each row has the
same answer on this prefix as on the infinite input. Every certified output equals $F(x)(n)$ by
uniqueness of numerical outputs. Conversely, totality supplies a finite certificate for each
$F(x)(n)$, so the corresponding row forces $y(n)=F(x)(n)$. Thus all rows hold exactly on $G_F$.
An unused second branch coordinate turns this recursive prefix condition into a pair-tree presentation.

Intersect $G_F$ with $\NameProjection{2}{\cdot}^{-1}(A)$ and project onto the first coordinate.
The constructions of §{sec:edst-coordinate-projections} give exactly $F^{-1}(A)$ and retain the same
parameter. No bound on the running time or input use of $F$ is assumed. Totality is used to ensure
that each output coordinate eventually has a certificate, not to decide when arbitrary programs halt.
\end{proof}

### Numerical quantifiers with a Baire-space input {#sec:edst-baire-quantifiers}

\begin{mathmeta}
  \vars{x}{Name}
  \vars{k}{Nat}
  \vars{q}{Name}
  \vars{n}{Nat}
\end{mathmeta}

\begin{proposition*}[\termdefineas{numerical quantifiers with a Baire-space input}{Numerical
quantifiers with a Baire-space input}]
Fix $\varepsilon\in\BaireSpace$. Suppose one closed lambda program, with input name
$\NamePair{\varepsilon}{x}$ and numerical argument $\NatPair{n}{k}$, decides $R(x,n,k)$ for all
$x\in\BaireSpace$ and $n,k\in\NN$. Then
$$A:=\{x:\forall n\,\exists k\ R(x,n,k)\}$$
and its complement have pair-tree presentations decidable relative to $\varepsilon$.
The set $\{x:\exists n\,\forall k\ R(x,n,k)\}$ also has such a presentation.
\end{proposition*}

\begin{proof}[Proof]
First consider any predicate $S(x,i)$ decided by one such total program. Let $F(x)(i)$ be its decision
bit. This program computes the Baire-space map $F$. The singleton consisting of the constant-one
sequence has a pair-tree presentation: on equal-length words require every entry of the first word
to be one, leaving the second word unrestricted. List access, equality, and a bounded product decide
this finite condition. The computable-inverse-image construction gives a tree presentation of
$\{x:\forall i\ S(x,i)\}$ as the inverse image of that singleton. No advance bound on the input
positions read by the decision program is needed.

For $A$, work on a coded pair $\NamePair{x}{q}$ and test $R(x,n,q(n))$ in row $n$.
The parameter and the first point coordinate can be passed to the original program, while the
second coordinate supplies the numerical witness. The explicit accessors in
§{sec:lambda-graph-tests} give a total row program at the same parameter.
Apply the preceding construction and project onto $x$. A branch supplies a witness for each $n$;
conversely, choosing the numerical witnesses gives a sequence $q$. This last step proves existence,
without asserting that a suitable sequence can be computed from $x$.

For $\exists n\,\forall k\ R(x,n,k)$, store the chosen number in $q(0)$ and test
$R(x,q(0),k)$ in row $k$. Again take the inverse image of the constant-one singleton and project.
Finally apply this construction to $\neg R$ to obtain the complement of $A$.
All trials terminate by hypothesis, but their running times and input uses may depend on every
argument. The construction retains the original parameter throughout.
\end{proof}

\begin{proposition*}[\termdefineas{uniform countable union of relative projections}{Uniform countable unions}]
Under this uniformity hypothesis, a pair tree $U$ recursive relative to $\varepsilon$ satisfies
$$\begin{aligned}
[U]&=\{\Pair{x}{q}:\Pair{x}{\Sequence{q(n+1)}{n\in\omega}}\in[T_{q(0)}]\},\\
\pi_0([U])&=\bigcup_i\pi_0([T_i]).
\end{aligned}$$
\end{proposition*}

\begin{proof}[Proof]
Use the finite-test construction of §{sec:edst-finite-check-trees} with
$$\begin{aligned}
R(s,[])&\quad\Longleftrightarrow\quad\text{true},\\
R(s,i::t)&\quad\Longleftrightarrow\quad\Pair{\restrict{s}{\Length{t}}}{t}\in T_i.
\end{aligned}$$
The head and tail of a list, its length, and prefix extraction are computed by total numerical lambda
terms, so the joint decider decides this test at the original parameter. A branch passes the test at
length $n+1$ exactly when the length-$n$ prefixes of its first coordinate and shifted witness lie in the
tree selected by its first witness entry. This proves the body identity. Taking that entry as the chosen
index gives one projection inclusion. For the other, prepend the chosen index to a witness in its tree.
The empty-prefix test always passes, but the test at length one checks the empty node of the selected
tree. Thus an empty selected tree produces no spurious branch.
\end{proof}

\begin{mathmeta}
  \define{WitnessRow}
\end{mathmeta}
For intersections, store all witnesses in one sequence, with row $i$ occupying positions $\NatPair{i}{j}$.
For finite words define
$$\WitnessRow{v}{i}{k}:=[v^*_{\NatPair{i}{j}}]_{j<k},\qquad
v^*_r:=\begin{cases}v_r,&r<\Length{v},\\0,&r\ge\Length{v}.\end{cases}$$
Entries are listed in increasing order of $j$. If $\NatPair{i}{k}<\Length{v}$, every entry used in this row exists:
numerical pairing is strictly increasing in its second argument. Consequently,
$$\WitnessRow{\restrict{q}{n}}{i}{k}
 =\restrict{\Sequence{q(\NatPair{i}{j})}{j\in\omega}}{k}
 \quad\text{when }\NatPair{i}{k}<n.$$
The guard is sufficient, though it need not be the earliest stage at which the row can be read.

\begin{proposition*}[\termdefineas{uniform countable intersection of relative projections}{Uniform countable
intersections}]
Under the same uniformity hypothesis, a pair tree $V$ recursive relative to $\varepsilon$ satisfies
$$\begin{aligned}
[V]&=\{\Pair{x}{q}:\forall i\ \Pair{x}{\Sequence{q(\NatPair{i}{j})}{j\in\omega}}\in[T_i]\},\\
\pi_0([V])&=\bigcap_i\pi_0([T_i]).
\end{aligned}$$
\end{proposition*}

\begin{proof}[Proof]
Apply the finite-test construction to
$$\begin{aligned}
R(s,v)\quad\Longleftrightarrow\quad
 &\forall i<\Length{s}\ \forall k<\Length{s},\\
 &\NatPair{i}{k}<\Length{v}\ \Longrightarrow
 \Pair{\restrict{s}{k}}{\WitnessRow{v}{i}{k}}\in T_i.
\end{aligned}$$
Finite tabulation computes the row, and two bounded products decide the two finite universal quantifiers.
The concrete terms are given in §{sec:lambda-projection-programs}. Every call uses the original
parameter. Suppose all prefix tests pass. For any $i,k$, choose
$n=\NatPair{i}{k}+i+k+1$. The length-$n$ test includes this pair of indices and its guard holds.
The row identity then gives the required length-$k$ node in $T_i$. Conversely, if every row is a witness,
that identity verifies each guarded finite test. This proves the body identity.

For the projection identity, each row of a new witness gives a witness in its corresponding tree.
Conversely, choose witnesses $q_i$ for a point in every projection and define
$q(\NatPair{i}{j})=q_i(j)$. Pairing is a bijection, so this defines a single sequence with exactly those
rows. This use of countable choice proves existence; it does not assert a computable selection of witnesses.
The case $k=0$ is tested at a sufficiently long prefix for every $i$, so an empty component tree also
makes the new body empty.
\end{proof}

\begin{corollary*}[Uniform presentations of sets and complements]
Suppose $A_i$ and $A_i^c$ have pair-tree presentations jointly decidable in the index and node relative
to the same $\varepsilon$, separately for the two families. Then both the union and the intersection
have such relative presentations, as do their complements. In particular, both sets are Borel.
\end{corollary*}

\begin{proof}[Proof]
Apply the two constructions to the two families and use De Morgan's identities. A relative pair-tree
projection is analytic, so each resulting set and its complement are analytic. The Suslin theorem gives
Borelness. This argument gives relative tree presentations; it does not yet construct effective Borel
codes or a uniform effective separator.
\end{proof}

### Arithmetic formulas and pair-tree normal form {#sec:edst-arithmetic-normal-form}

\begin{mathmeta}
  \vars{q,x}{Name}
  \vars{n}{Nat}
  \vars{z}{Name}
\end{mathmeta}

Fix the parameter $\varepsilon$. We encode a numerical variable together with an input sequence by
\begin{mathmeta}
  \define{NumberBinding}
\end{mathmeta}
$$\NumberBinding{n}{x}(k):=\NatPair{n}{x(k)}.$$
The first projection at coordinate zero recovers $n$, and the second projection at every coordinate
recovers $x$. Repeating this operation encodes finitely many numerical variables. Each binding and
projection uses the numerical pairing programs already constructed.

A predicate is \termdefine{arithmetical relative to a real parameter} if it is obtained by finitely many
Boolean operations and natural-number quantifiers from predicates decided by a single total lambda
program on input $\NamePair{\varepsilon}{x}$. At each numerical quantifier, the new variable is encoded
by $\NumberBinding{n}{x}$. Thus existential and universal quantification applied to a predicate $B$
give $\exists n\ B(\NumberBinding{n}{x})$ and $\forall n\ B(\NumberBinding{n}{x})$.
There is no bound on the finite number of quantifiers or their alternations. Quantification over
infinite sequences is not part of this arithmetic formation rule.

\begin{lemma*}[\termdefineas{numerical sections of relative tree projections}{Numerical sections of tree projections}]
If $A$ has a pair-tree presentation decidable relative to $\varepsilon$, then the sets
$$A_n:=\{x:\NumberBinding{n}{x}\in A\}$$
have a uniformly decidable family of such presentations at the same parameter. Consequently both
$\{x:\exists n\ \NumberBinding{n}{x}\in A\}$ and
$\{x:\forall n\ \NumberBinding{n}{x}\in A\}$ have relative pair-tree presentations.
\end{lemma*}

\begin{proof}[Proof]
Choose a tree $T$ presenting $A$. For a finite word $s$, let $s_n$ have entries
$s_n(k)=\NatPair{n}{s(k)}$. Put
$$T_n:=\{\Pair{s}{t}:\Pair{s_n}{t}\in T\}.$$
Mapping entries preserves length and commutes with truncation, so these are synchronized trees.
The numerical program in §{sec:lambda-arithmetic-normal-form-programs} computes the code of $s_n$
jointly from $n$ and the code of $s$. Pairing it with the code of $t$ and running the fixed decider
for $T$ gives one joint decider for the family. On infinite branches the same identity gives
$\pi_0([T_n])=A_n$. Apply the uniform countable-union and countable-intersection constructions.
The joint decider, rather than a separate choice of a decider for each $n$, justifies these applications.
\end{proof}

\begin{proposition*}[\termdefineas{relative tree presentations of arithmetic predicates}{Arithmetic
predicates and their complements}]
Every arithmetical predicate relative to $\varepsilon$, and its negation, has a pair-tree presentation
decidable at that same parameter.
\end{proposition*}

\begin{proof}[Proof]
Induct on the finite formation of the predicate. For an atomic predicate, repeat its decision bit
in every output coordinate and use the constant-one inverse-image construction of
§{sec:edst-baire-quantifiers}. Reversing the decision bit handles its negation.
Negation exchanges the two presentations. Conjunction uses intersection for the positive side and
union for the negative side; disjunction follows by De Morgan's identity. For a numerical quantifier,
apply the preceding lemma to both presentations: existential quantification uses union on the positive
side and intersection on the negative side, and universal quantification reverses those roles.
This proves every finite step without changing the parameter or requiring a computable choice of witnesses.
\end{proof}

\begin{theorem*}[\termdefineas{arithmetic pair-tree normal form}{Arithmetic pair-tree normal form}]
A set $A\IncludedIn\BaireSpace$ has a pair-tree presentation decidable relative to $\varepsilon$
if and only if there is an arithmetical predicate $B$ relative to $\varepsilon$ such that
$$x\in A\quad\Longleftrightarrow\quad\exists q\in\BaireSpace\ B(\NamePair{x}{q}).$$
\end{theorem*}

\begin{proof}[Proof]
Suppose first that the displayed formula holds for an arithmetical predicate $B$. The preceding
proposition presents $B$ by a relative pair tree.
Project onto the first point coordinate as in §{sec:edst-coordinate-projections}; the omitted real
and the tree witness are paired into one witness.

Conversely, let $T$ present $A$. On a coded pair $z=\NamePair{x}{q}$, set
$$B(z):\Longleftrightarrow\forall n\ \Pair{
 \restrict{x}{n}}{\restrict{q}{n}}\in T.$$
The row predicate is decidable uniformly from $\NumberBinding{n}{z}$ with parameter $\varepsilon$:
read $n$, read exactly the first $n$ coordinates of $x$ and $q$, and pass their paired list codes
to the decider for $T$. The finite-prefix reader and the accessors in
§{sec:lambda-arithmetic-normal-form-programs} give one total closed term for this test.
Thus $B$ is an atomic predicate followed by one universal natural-number quantifier, and the displayed
existential-real formula says exactly that $x$ lies in the projection of $[T]$.
\end{proof}

### Uniform indices for pair-tree projections {#sec:edst-pair-tree-indices}

\begin{mathmeta}
  \vars{e,i}{Nat}
  \vars{b,j}{Nat}
  \vars{n}{Nat}
\end{mathmeta}

Fix a parameter $\varepsilon$ and enumerate the closed lambda programs as $P_e$ using their syntax codes.
The finite-certificate checker in §{sec:lambda-input-universal-evaluation} gives a total zero/one test
$C(e,a,b)$: it returns one exactly when a certificate within bound $b$ proves that $P_e$, with parameter
$\varepsilon$, returns zero on input code $a$. Every actual zero output has such a certificate for some bound.
This test is uniform in all three numerical arguments and uses the same fixed parameter.

\begin{theorem*}[\termdefine{Uniform pair-tree presentations}]
There is a family $\Sequence{T_e}{e\in\NN}$ of trees recursive relative to $\varepsilon$ whose membership is jointly
decidable in $e$ and the finite node. If $P_e$ decides membership in a pair tree $T$, then $[T_e]=[T]$ and
$\pi_0([T_e])=\pi_0([T])$. Consequently the projections of this family are exactly the projections of pair trees
recursive relative to $\varepsilon$.
\end{theorem*}

\begin{proof}[Proof]
For a finite pair $\Pair{s}{t}$, require $\Length{s}=\Length{t}$ and put $n=\Length{s}$. For each $i<n$, decode
$i=\NatPair{j}{b}$ and
perform the test
$$C\!\left(e,\NatPair{\LambdaListCode{\restrict{s}{j}}}{\LambdaListCode{\restrict{t}{j}}},b\right).$$
Put $\Pair{s}{t}\in T_e$ exactly when all these answers are zero. There are only finitely many terminating tests,
so one program decides the family. The empty pair passes because there are no trials. The numerical pairing
satisfies $j\le i$. On truncation to length $m\le n$, every trial $i<m$ therefore examines the same pair of
prefixes as before. Thus membership is preserved by truncation, for every index, including indices of partial
programs.

Now suppose $P_e$ decides $T$. If $\Pair{p}{q}\in[T]$, every tested prefix has answer one from the decider, so no
sound certificate can prove answer zero; all finite pairs on this branch belong to $T_e$. Conversely, if a
prefix of length $j$ fails membership in $T$, its decision returns zero. Choose a certificate bound $b$, put
$i=\NatPair{j}{b}$, and take $n=i+1$. The length-$n$ pair fails trial $i$, so $\Pair{p}{q}\notin[T_e]$. This proves
both body inclusions and hence equality of projections. Every relative pair tree has a deciding index, and
every index in the displayed family gives a relative pair tree, proving the final assertion.
\end{proof}

The construction delays rejection; it preserves the body and projection of a correctly decided tree, rather than
its individual finite nodes or well-founded rank. If a program never returns zero on any numerical input,
its tree is the full synchronized tree, since no rejecting certificate exists. This family therefore requires
no decision of totality and does not enumerate the characteristic functions of all recursive trees.

\begin{proposition*}[\termdefine{Specialization of relative tree families}]
Let $\Sequence{S_i}{i\in\omega}$ be pair trees whose membership is jointly decidable relative to $\varepsilon$. There is
a numerical
function $f$, computed by an ordinary closed lambda term, such that $P_{f(i)}$ decides membership in $S_i$.
In particular, $[T_{f(i)}]=[S_i]$.
\end{proposition*}

\begin{proof}[Proof]
Fix a closed family decider $P$. Insert the numeral for $i$ into the template
$$\lambdaab{o}{\lambdaab{z}{Po(\LambdaNumericPair\,\ChurchNumeral{i}\,z)}}.$$
Two outer beta steps and numerical pairing reduce this program to the family decision on the pair of $i$ and
the node code. The syntax-code constructors and numeral-code program compute the code of this template from
$i$, without querying $\varepsilon$. This is the required function $f$. The preceding theorem gives the body
identity. The concrete code recipe and the finite-test program are detailed in §{sec:lambda-pair-tree-programs}.
\end{proof}

## Lightface and Boldface Classes {#sec:lightface-boldface}

In this subsection, unadorned \termdefineas{lightface class}{lightface pointclasses} such as $\lSigma^0_1$, $\lPi^0_1$,
and $\lSigma^1_1$ are classes of subsets of $\BaireSpace$. If the ambient space matters, we say it in words rather than

$\lDelta^k_n(a)$. Here "real" is used in the descriptive-set-theoretic sense: an element of $\BaireSpace$ is a Baire
real, i.e. an infinite sequence of natural numbers used as a code or parameter. The spaces
$\BaireSpace$, $\CantorSpace$, and $\R$ are mutually intercodable at the standard Borel level.
Effective statements, however, use the specified presentation and coding; arbitrary Borel isomorphisms need not
preserve computability or lightface complexity.

Fix a standard recursive coding of finite sequences and a recursive enumeration $\IndexedFamily{W_e}{e\in\omega}$ of the
recursively enumerable subsets of $\omega$. Define lightface classes inductively:

*   $\lSigma^0_1$: the *effectively open* sets — those expressible as $\bigcup_{e \in W} \cyl{\sigma(e)}$ for a
    recursively enumerable index set $W \IncludedIn \omega$ and a fixed recursive enumeration $\sigma : \omega \to
    \finseq{\omega}$ of finite sequences.
*   $\lPi^0_n$: complements of $\lSigma^0_n$ sets.
*   $\lSigma^0_{n+1}$: effective countable unions of uniformly $\lPi^0_n$ sets; equivalently, sets of the form
    $\{p:\exists k\;\Pair{k}{p}\in P\}$ for a $\lPi^0_n$ set $P\IncludedIn\omega\times\BaireSpace$.
*   $\lSigma^1_1$: projections to $\BaireSpace$ of $\lPi^0_1$ (effectively closed) subsets of $\BaireSpace \times
    \BaireSpace$.
*   $\lPi^1_n$, $\lSigma^1_{n+1}$: as in the boldface case but with the base level taken from the lightface side.
*   $\lDelta^k_n \;=\; \lSigma^k_n \cap \lPi^k_n$.

The enumeration $\IndexedFamily{W_e}{e\in\omega}$ is bookkeeping, not extra structure in the pointclass. It supplies
indices for
recursively enumerable sets, so that effectively open sets can be coded. If one replaces it by another standard
effective enumeration, the indices change but the class $\lSigma^0_1$ does not: the same recursively enumerable subsets
of $\omega$ are being listed. The same applies to the fixed coding $\sigma:\omega\to\finseq{\omega}$ of finite
sequences. These choices affect codes, not the underlying lightface classes.

Thus membership in a $\lSigma^0_1$ set is semidecidable: given $p \in \BaireSpace$, search the enumeration of cylinders
until one appears whose finite word is an initial segment of $p$. If $p \in U$, the search eventually halts; if $p
\notin U$, it may run forever. Dually, membership in a $\lPi^0_1$ set is co-semidecidable.

The effective closed-set tree representation proved in §{sec:edst-recursive-trees} says that $F\IncludedIn\BaireSpace$
is $\lPi^0_1$ exactly when $F=[T]$ for a recursive tree $T\IncludedIn\finseq{\omega}$.

Effective analytic sets are projections of recursive trees. More explicitly, $A \IncludedIn \BaireSpace$ is
$\lSigma^1_1$

The \termdefineas{boldface class}{boldface classes} are recovered by **\termforward{relativization}**. Fix a real
$a \in \BaireSpace$

recursive relative to $a$. And $A\IncludedIn\BaireSpace$ lies in $\lSigma^1_1(a)$ iff there is an $a$-recursive tree

The resulting relativized classes are denoted $\lSigma^k_n(a)$, $\lPi^k_n(a)$, and $\lDelta^k_n(a)$. Then

The slogan is *boldface = lightface relativized to all real parameters*.

This slogan should be read literally. A boldface open set may require a noncomputable list of cylinders. Treat that list
as a real parameter $a$, give the program input-function access to $a$, and the same set becomes lightface relative to
$a$. The topological hierarchy is therefore the union of all its computable versions relative to all possible real
parameters.

## Universal Sets and Strict Hierarchies {#sec:edst-universal}

\begin{mathmeta}
  \vars{q}{Name}
  \vars{e}{Nat}
  \vars{n}{Nat}
  \vars{p}{Name}
  \vars{\sigma}{Fun(Nat,Seq(Nat))}
  \vars{U_*}{Set(Name)}
\end{mathmeta}

<!-- formalization: skip (section lead-in) -->
For the lightface classes used here, a single set parameterizes all members of the class. The standard diagonal argument
applied to that parameterization gives strictness in sharpened form.

\begin{theorem*}[$\lSigma^0_1$ universal set]
Let $\sigma : \omega \to \finseq{\omega}$ be a fixed recursive enumeration of finite sequences and
$\IndexedFamily{W_e}{e\in\omega}$ the standard listing of recursively enumerable subsets of $\omega$. The set
$$
U:=\bigcup_{e\in\omega}\bigcup_{n\in W_e}\bigl(\{e\}\times\cyl{\sigma(n)}\bigr)
\IncludedIn\omega\times\BaireSpace
$$
is a \termdefineas{lightface Sigma01 universal set}{$\lSigma^0_1$-universal set}: it is effectively open, and every
$\lSigma^0_1$ subset of $\BaireSpace$ is a section $U_e:=\{p:\Pair{e}{p}\in U\}$.
\end{theorem*}

\begin{proof}[Proof]
The pairs of cylinders in the displayed union are recursively enumerable, so the union is effectively open in the
product of the discrete space $\omega$ and $\BaireSpace$. Conversely, an effectively open set is given by some
recursively enumerable list of cylinders, hence by some $W_e$, and therefore equals $U_e$. Equivalently, one may use
semidecidability: a halting computation reads only finitely much of $p$, so its accepting finite transcripts enumerate
cylinders. This is the finite-use principle from §{sec:lambda-baire-space}.
\end{proof}



\begin{lemma*}[First-coordinate diagonal]
For any family $\Sequence{U_e}{e\in\omega}$ of subsets of $\BaireSpace$, define
$$D:=\{p\in\BaireSpace:p\notin U_{p(0)}\}.$$
Then $D\ne U_e$ for every $e\in\omega$.
\end{lemma*}

\begin{proof}[Proof]
If $D=U_e$, choose any $p$ with $p(0)=e$. Then
$$p\in D\quad\Longleftrightarrow\quad p\notin U_e\quad\Longleftrightarrow\quad p\notin D,$$
a contradiction.
\end{proof}

\begin{theorem*}[Strictness at the first lightface level]
$\lSigma^0_1\ne\lPi^0_1$ on $\BaireSpace$.
\end{theorem*}

\begin{proof}[Proof]
For the universal set above, put
$$D \;:=\; \{p \in \BaireSpace : \Pair{p(0)}{p} \notin U\}.$$
The complement of $D$ is the recursive preimage of $U$ under $p\mapsto\Pair{p(0)}{p}$, so it is $\lSigma^0_1$ and $D$ is
$\lPi^0_1$. If $D$ were also $\lSigma^0_1$, universality would make it a section $U_{e_0}$, contradicting the
first-coordinate diagonal lemma.
\end{proof}

\begin{theorem*}[Effective analytic universal set and strictness]
There is a $\lSigma^1_1$ set $V\IncludedIn\omega\times\BaireSpace$ whose sections are exactly the $\lSigma^1_1$ subsets
of $\BaireSpace$. Consequently $\lSigma^1_1\ne\lPi^1_1$. For every real $a$, the same conclusion holds relative to
$a$: $\lSigma^1_1(a)\ne\lPi^1_1(a)$.
\end{theorem*}

\begin{proof}[Proof]
Combine the recursive pair-tree normal form for analytic predicates with §{sec:edst-pair-tree-indices} to obtain
a uniformly recursive sequence $\Sequence{T_e}{e\in\omega}$ representing every $\lSigma^1_1$ set by projection. The
delayed
finite-certificate construction supplies a total family of tree deciders without testing whether the original
programs are total. Set
$$
V:=\{\Pair{e}{p}:\exists q\in\BaireSpace\ \forall n\;
  \Pair{\restrict{p}{n}}{\restrict{q}{n}}\in T_e\}.
$$
This is $\lSigma^1_1$, and the pair-tree representation makes every $\lSigma^1_1$ set a section $V_e$. Now put
$E:=\{p:\Pair{p(0)}{p}\notin V\}$. Its complement is the recursive preimage of $V$ under $p\mapsto\Pair{p(0)}{p}$, so
$E$ is
$\lPi^1_1$. If it were $\lSigma^1_1$, say $E=V_e$, then evaluating at a real $p$ with $p(0)=e$ would give $p\in E$ if
and only if $p\notin E$. With a fixed oracle $a$, use the same recursive normal form relative to $a$; every step and the
diagonal carry that oracle, so the proof relativizes verbatim.
\end{proof}

## Recursive Ordinals and the Hyperarithmetic Hierarchy {#sec:hyperarithmetic-hierarchy}

\begin{mathmeta}
  \vars{e}{Nat}
  \vars{b,k,n,t}{Nat}
\end{mathmeta}
\index{recursive ordinal}

<!--

\termdefine{hyperarithmetic hierarchy} has three ingredients: the jump operator on relative-computability degrees, a
system of ordinal notations, and iteration of the jump along those notations. The classical names "Turing degree" and

**The jump.** For $A\IncludedIn\omega$, write $\chi_A(n)=1$ if $n\in A$ and $\chi_A(n)=0$ otherwise.
The \termdefine{Turing jump} is
$$A':=\{e\in\omega:\varphi_e^A(e)\downarrow\},$$
where $\varphi_e^A$ is the partial numerical function of the closed lambda program $P_e$, with access to
$\chi_A$. Here halting means returning a Church numeral by finitely many beta/query steps; reaching an
arbitrary normal form is not enough.

\begin{proposition*}[\termdefineas{relative jump strictness}{Strict increase under the relative jump}]
The set $A'$ is semidecidable relative to $A$, whereas its complement is not.
Moreover, $\chi_A$ is computable relative to $\chi_{A'}$, but $\chi_{A'}$ is not computable relative to $\chi_A$.
\end{proposition*}

\begin{proof}[Proof]
To semidecide $A'$, search the finite reduction certificates for $P_e$ on input $e$, allowing every possible
numerical output. The exact search construction returns one if a certificate exists and has no numerical
output otherwise. If the complement were semidecidable, the equivalence between acceptance and numerical
halting domains would give a closed program $D$ whose domain is that complement. At an index $d$ of $D$,
its computation on $d$ would halt exactly when it did not halt, a contradiction. In particular, a decision
program for $A'$ cannot exist.

For the other direction, form a program that ignores its numerical input and searches for a nonzero answer
to the fixed query $\chi_A(n)$. Its domain is all of $\NN$ if $n\in A$ and empty otherwise. Inserting
$\ChurchNumeral{n}$ into this fixed template gives an index $f(n)$, and the syntax-code constructors compute
$f$ by a closed numerical lambda term. Thus $f(n)\in A'$ exactly when $n\in A$. Querying $\chi_{A'}(f(n))$
therefore computes $\chi_A(n)$. The explicit terms and the preservation of numerical nontermination under
specialization are proved in §{sec:lambda-relative-jump}.
\end{proof}

For an arbitrary numerical parameter $\varepsilon$, let $K^\varepsilon$ be the set of indices whose
programs return a numeral on their own index with input function $\varepsilon$, and put
$\varepsilon':=\chi_{K^\varepsilon}$. Thus $(\chi_A)'=\chi_{A'}$.

\begin{proposition*}[\termdefineas{numerical quantifiers from jumps}{Numerical quantifiers from jumps}]
There are total numerical functions $\xi,\nu,\upsilon$, computed by closed lambda terms, with the following
properties for every $\varepsilon$. If $P_e$ decides $R(n,k)$ on input $\NatPair{n}{k}$ relative to
$\varepsilon$, then $P_{\xi(e)}$ decides $\exists k\,R(n,k)$ relative to $\varepsilon'$, and
$P_{\upsilon(e)}$ decides $\forall k\,R(n,k)$ relative to $\varepsilon'$.
If $P_e$ decides a numerical predicate $S$ relative to $\varepsilon$, then $P_{\nu(e)}$ decides its negation
at the same parameter. These functions can be chosen with $\upsilon=\nu\circ\xi\circ\nu$.
In particular, a decider for $R(n,t,b)$ on input $\NatPair{\NatPair{n}{t}}{b}$ yields a decider for
$\forall t\,\exists b\,R(n,t,b)$ at $(\varepsilon')'$ with index $\upsilon(\xi(e))$.
\end{proposition*}

\begin{proof}[Proof]
First reduce arbitrary numerical halting to diagonal halting. Insert $\ChurchNumeral{n}$ into the closed
program $\lambdaab{o}{\lambdaab{t}{P_eo\ChurchNumeral{n}}}$, and let $h(e,n)$ be its syntax index.
The code constructors compute $h$, independently of $\varepsilon$. Two beta steps discard $t$;
confluence gives the reverse implication for every numeral output. Hence
$$h(e,n)\in K^\varepsilon\quad\Longleftrightarrow\quad
  \exists m\;\LambdaInputSteps{\varepsilon}{P_eo\ChurchNumeral{n}}{\ChurchNumeral{m}}.$$
A query to $\varepsilon'$ therefore decides this halting question.

Next construct a program that searches $k=0,1,\ldots$ for an accepting computation of $P_e$ on
$\NatPair{n}{k}$. Since $P_e$ is a decider, every trial terminates. Exact search returns one when a
witness exists and has no numerical output otherwise. Apply the halting query to this search program.
The search template and its halting-query wrapper have syntax codes computable from $e$; this gives
$\xi$. Reversing a decision bit gives $\nu$. Applying this reversal before and after the existential
construction gives $\upsilon$, since $\forall k\,R(n,k)$ is equivalent to $\neg\exists k\,\neg R(n,k)$.
Apply the existential and universal constructions successively for the last assertion.
§{sec:lambda-relative-jump} gives the closed templates and their code transformations.
\end{proof}

\begin{mathmeta}
  \define{churchKleeneOrd,relativeChurchKleeneOrd}
\end{mathmeta}

**Recursive ordinals.** A \termdefine{recursive ordinal} is the order type of a computable linear order on a
computable subset of $\NN$ that is externally well founded. More generally, a presentation relative to
$\varepsilon$ consists of a domain $D\IncludedIn\NN$ and a relation $R$ on $\NN$, with total lambda
membership and comparison programs at $\varepsilon$, such that the restriction of $R$ to $D$ is a strict
well order. No requirement is placed on comparisons outside $D$. Well-foundedness is a hypothesis about
the presentation, not a property these programs must decide.
Write $\relativeChurchKleeneOrd{\varepsilon}$ for the supremum of the order types of these presentations.
For the constant-zero parameter this is the \termdefineas{Church--Kleene ordinal}{Church--Kleene ordinal}
$\churchKleeneOrd$. Substituting a closed implementation of the zero function eliminates the parameter,
as proved in §{sec:lambda-recursive-order-programs}.

\begin{proposition*}[\termdefineas{boundary of relative recursive ordinals}{Boundary of relative recursive ordinals}]
For each fixed $\varepsilon$, the ordinal $\relativeChurchKleeneOrd{\varepsilon}$ is countable and has no
presentation recursive relative to $\varepsilon$. An ordinal has such a presentation if and only if it is
strictly below $\relativeChurchKleeneOrd{\varepsilon}$. In particular, $\churchKleeneOrd$ is the least
nonrecursive ordinal.
\end{proposition*}

\begin{proof}[Proof]
There are countably many domain and comparison predicates at a fixed parameter: choose numerical indices
for their two closed decision programs, and use uniqueness of outputs. Hence there are countably many
presentations. Every domain is a subset of $\NN$, so every order type is countable. Their supremum is
countable as well, by the countability of a countable union of countable sets. This argument does not
decide which program pairs present well orders.

Two concrete operations on presentations finish the proof. Given $a\in D$, keep the comparison relation
and replace the domain by
$$D_{<a}:=\{n\in D:n\mathrel R a\}.$$
Its decider multiplies the membership bit and the comparison bit with the fixed constant $a$. Its order
type is the position of $a$ in the original well order. Every smaller ordinal occurs at such a position,
so the represented ordinals are downward closed.

For a successor, put
$$D^+:=\{0\}\cup\{n+1:n\in D\}.$$
Make zero the largest element, with
$$n+1\mathrel{R^+}0,\qquad
 n+1\mathrel{R^+}(m+1)\ \Longleftrightarrow\ n\mathrel R m,$$
and no comparison $0\mathrel{R^+}b$. Zero testing, predecessor, and the old two deciders give total
programs for this presentation; their explicit terms are in §{sec:lambda-recursive-order-programs}.
The map sending $n$ to $n+1$, together with the new largest element, identifies its order type with the
old order type plus one. The empty domain presents zero, so finite iteration also presents every finite ordinal.

Every represented ordinal is therefore strictly below the supremum: its successor is still represented.
The supremum cannot itself be represented, for then its successor would exceed the supremum. Finally,
if an ordinal is strictly below the supremum, some presented order type exceeds it; the initial-segment
construction gives a presentation of that ordinal. This proves all the assertions.
\end{proof}

### Recursive bounds for tree ranks {#sec:edst-recursive-tree-ranks}

\begin{mathmeta}
  \define{kleeneBrouwerOrder}
\end{mathmeta}

For finite words $s,t$, define the \termdefine{Kleene--Brouwer order} by placing a proper extension before
its prefix and otherwise comparing the first differing entries. Equivalently, its clauses are
$$\begin{aligned}
&\neg(\kleeneBrouwerOrder{[]}{t}),\qquad \kleeneBrouwerOrder{a::s}{[]},\\
&\kleeneBrouwerOrder{a::s}{b::t}
 \quad\Longleftrightarrow\quad a<b\ \lor\ (a=b\ \land\ \kleeneBrouwerOrder{s}{t}).
\end{aligned}$$
Thus the end of a word is treated as larger than every natural-number entry. This is a strict linear
order on finite words. It need not be well founded on all finite words.

\begin{proposition*}[\termdefineas{recursive tree rank bound}{Recursive bound for a well-founded tree}]
Let $T$ be a tree on $\NN$ whose membership is decidable relative to $\varepsilon$, and suppose $T$ is
well founded. The Kleene--Brouwer order on its list codes is a well-order presentation at the same
parameter. If $\alpha$ is its order type, then
$$\rho_T(s)<\alpha<\relativeChurchKleeneOrd{\varepsilon}\qquad(s\in T).$$
In particular, the rank of every recursive well-founded rooted tree is below $\churchKleeneOrd$.
\end{proposition*}

\begin{proof}[Proof]
The comparison clauses give irreflexivity, transitivity, and trichotomy by induction on words. We prove
well-foundedness by induction on strict extension in $T$. At a node $s$, the induction assertion is that
every nonempty subset $A$ of its cone has a least element in the Kleene--Brouwer order. If $A$ contains
no proper extension of $s$, its only element is $s$. Otherwise, choose the least $n$ such that the cone
above $s\concat(n)$ meets $A$, where $s\concat(n)$ denotes appending $n$ to $s$. The child $s\concat(n)$ belongs to
$T$ by closure under prefixes. The induction hypothesis gives a least element $m$ in that intersection.
Every other member of $A$ is either $s$, lies above the same child, or lies above a child with larger
index. In the first and third cases it follows after $m$; in the second it cannot precede $m$ by the
choice of $m$. This proves the induction assertion. For a nonempty tree apply it at the empty word;
the empty tree is immediate. The choices here prove well-foundedness and are not asserted to be
computable from an arbitrary subset $A$.

List encoding is a bijection with $\NN$, so the original membership program decides the domain of
codes without any extra validity test. The comparison clauses give a total lambda program by recursion
on the first word, as constructed in §{sec:lambda-kleene-brouwer}. This comparison makes no parameter
queries. Consequently the coded order is a presentation at the original $\varepsilon$, and its order
type $\alpha$ is below $\relativeChurchKleeneOrd{\varepsilon}$.

Every strict extension precedes its prefix in this order. Induction on strict extension therefore
bounds the rank of each node by its position in the well order: the successor of each child rank is
at most the position of its parent, and taking their supremum preserves that inequality. Each such
position is strictly below $\alpha$, proving the displayed bound. For a rooted tree apply it at the
root. The constant-zero parameter gives the final assertion.
\end{proof}

### Ordinal notations and iterated jumps {#sec:edst-ordinal-notations}

\begin{mathmeta}
  \define{KleeneO,KleeneCandidateStep,KleeneCandidatePrecedes,KleenePrecedes,KleeneValue}
  \vars{k}{Nat}
  \vars{a,b,c,d,m,n,q,r}{Nat}
\end{mathmeta}
We construct \termdefineas{Kleene's ordinal notations}{Kleene's system of ordinal notations} $\KleeneO$ using the
ordinary unary program enumeration from §{sec:lambda-universal-evaluation}. Thus $\varphi_e(n)=m$ means that the
closed lambda program $P_e$ applied to $\ChurchNumeral{n}$ reduces to $\ChurchNumeral{m}$ by finitely many beta steps.
Here no input oracle is supplied. Numerical output is unique.

First define a candidate relation on all natural numbers by the rules
$$\KleeneCandidateStep{a}{2^a}\quad(a>0),\qquad
\KleeneCandidateStep{\varphi_e(n)}{3\cdot5^e}\quad(\varphi_e(n)\downarrow),$$
and write $\KleeneCandidatePrecedes{a}{b}$ for its transitive closure. These rules do not yet assert that any of the
numbers are valid notations. Define $\KleeneO$ as the least set closed under the following rules: $1\in\KleeneO$;
if $a\in\KleeneO$, then $2^a\in\KleeneO$; and if $\varphi_e$ is total, every $\varphi_e(n)$ belongs to
$\KleeneO$, and $\KleeneCandidatePrecedes{\varphi_e(n)}{\varphi_e(n+1)}$ for every $n$, then
$3\cdot5^e\in\KleeneO$. Finally, let $\KleenePrecedes{a}{b}$ be the transitive closure of the candidate steps
whose target belongs to $\KleeneO$.

\begin{proposition*}[\termdefineas{Kleene notation generation}{Generation of Kleene notations}]
If $b\in\KleeneO$ and $\KleeneCandidatePrecedes{a}{b}$, then $a\in\KleeneO$, and
$$\KleenePrecedes{a}{b}\quad\Longleftrightarrow\quad
b\in\KleeneO\ \text{ and }\ \KleeneCandidatePrecedes{a}{b}.$$
The candidate relation is well founded below each valid notation. Moreover, $\KleeneO$ and its precedence relation
form the least pair satisfying the simultaneous zero, successor and limit rules, with the limit rule requiring
$\KleenePrecedes{\varphi_e(n)}{\varphi_e(n+1)}$ for every $n$.
\end{proposition*}

The simultaneous rules in the proposition adjoin $1$; they adjoin $2^a$ and declare
$\KleenePrecedes{a}{2^a}$ whenever $a\in\KleeneO$; and they adjoin $3\cdot5^e$ and declare
$\KleenePrecedes{\varphi_e(n)}{3\cdot5^e}$ for every $n$ whenever the sequence is total, takes values in
$\KleeneO$, and is increasing in precedence. The relation is also required to be transitive.

\begin{proof}[Proof]
The three possible forms are disjoint: $1$ has no candidate predecessor, a power $2^a$ with positive exponent is even,
and
$3\cdot5^e$ is odd and at least three. Both coding functions are injective. Consequently the only candidate
predecessor of $2^a$, for $a>0$, is $a$. If $\varphi_e$ is total, the candidate predecessors of $3\cdot5^e$
are exactly its values, by uniqueness of numerical output. Induction on the generation of a valid notation now
shows both that every candidate predecessor is valid and that all such predecessors are accessible. This proves
well-foundedness below the notation. Applying predecessor validity along a finite chain proves downward closure
and the displayed equivalence.

The equivalence shows that the constructed pair satisfies the simultaneous rules. To prove minimality, let
$C$ and $R$ be any other set and transitive relation satisfying those rules. Induct on the generation of
$b\in\KleeneO$, proving together that $b\in C$ and that every $a$ with $\KleeneCandidatePrecedes{a}{b}$
belongs to $C$ and satisfies $R(a,b)$. The zero case has no predecessors. In the successor case, the last step
of any candidate chain enters from the preceding notation; apply the induction hypothesis and then the
successor rule for $R$. In the limit case, the induction hypotheses at consecutive sequence values turn their
candidate comparison into an $R$ comparison. The limit rules therefore apply. The last step of any chain into
the limit comes from one sequence value; its induction hypothesis and transitivity of $R$ finish the proof.
\end{proof}

\begin{proposition*}[\termdefineas{Kleene notation interpretation}{Ordinal interpretation of Kleene notations}]
There is a unique assignment of ordinals $a\mapsto\KleeneValue{a}$ on $\KleeneO$ satisfying
$$\KleeneValue{1}=0,\qquad
\KleeneValue{2^a}=\KleeneValue{a}+1,\qquad
\KleeneValue{3\cdot5^e}=\sup_n\KleeneValue{\varphi_e(n)},$$
where the last two equations apply to permitted successor and limit constructions.
Every value is countable, and $\KleenePrecedes{a}{b}$ implies $\KleeneValue{a}<\KleeneValue{b}$.
In particular, precedence is irreflexive.
\end{proposition*}

\begin{proof}[Proof]
Assign to a valid notation its rank for the candidate relation, namely the supremum of the successors of the
ranks of its immediate predecessors. The preceding proposition makes this recursion legitimate. Ranks strictly
increase along candidate steps and hence along finite chains. The descriptions of the predecessors give zero
at $1$ and the successor value at $2^a$. At a permitted limit, the rank is
$\sup_n(\KleeneValue{\varphi_e(n)}+1)$. Consecutive values strictly increase, so each summand is at most
$\KleeneValue{\varphi_e(n+1)}$; conversely each value is at most its successor. Thus this supremum equals
$\sup_n\KleeneValue{\varphi_e(n)}$. Uniqueness follows by induction on the same generation rules.

For countability, well-founded induction shows that every ordinal below an accessible number's rank is itself
the rank of an accessible number: choose a predecessor whose rank dominates the desired ordinal and continue
unless equality already holds. There are only countably many numbers, so every such rank is countable.
\end{proof}

Increase of the represented ordinals alone is not the defining condition for a permitted limit sequence;
the comparisons must hold in the generated precedence relation.

\begin{proposition*}[\termdefineas{downward closure of notation values}{Smaller ordinals below a notation}]
For $b\in\KleeneO$ and any ordinal $\alpha$,
$$\alpha<\KleeneValue{b}\quad\Longleftrightarrow\quad
 \exists a\in\KleeneO\;[\KleenePrecedes{a}{b}\;\land\;\KleeneValue{a}=\alpha].$$
\end{proposition*}

\begin{proof}[Proof]
The reverse implication follows from strict increase of values along precedence. For the forward implication, induct
on the generation of $b$. There is no ordinal below the value zero at $1$. If $b=2^c$, then
$\alpha\le\KleeneValue{c}$. In the equality case take $a=c$; in the strict case use the induction hypothesis below $c$
and append the successor step. If $b=3\cdot5^e$, the limit formula gives some $n$ with
$\alpha<\KleeneValue{\varphi_e(n)}$. Use the induction hypothesis there and append the limit step. All notations and
comparisons obtained this way are valid by the generation rules.
\end{proof}

\begin{mathmeta}
  \define{KleeneSuccIter,KleenePredMax}
\end{mathmeta}
Write $\KleeneSuccIter{a}{0}:=a$ and $\KleeneSuccIter{a}{k+1}:=2^{\KleeneSuccIter{a}{k}}$.
For a valid $a$, these are successive valid notations. In particular,
$\KleenePrecedes{\KleeneSuccIter{a}{k}}{\KleeneSuccIter{a}{k+1}}$.

\begin{theorem*}[\termdefineas{coverage of recursive ordinals by Kleene notations}{Notations for recursive ordinals}]
Every recursive ordinal has a Kleene notation. Thus for every $\alpha<\churchKleeneOrd$ there is
$a\in\KleeneO$ with $\KleeneValue{a}=\alpha$.
\end{theorem*}

\begin{proof}[Proof]
Fix a recursive well-order presentation $W=\Pair{D}{R}$. For each natural number $a$ and bound $n$, inspect the numbers
$k<n$ with $k\in D$ and $kRa$. Let $\KleenePredMax{a}{n}$ be zero if there are none, and $b+1$ if $b$ is their
$R$-greatest member. The extra one distinguishes a selected zero from an empty set. The finite scan is computable,
its selected member can only stay unchanged or increase, and every predecessor of $a$ is eventually at or below the
selected member. §{sec:lambda-recursive-order-programs} constructs the scan from the membership and
comparison terms.

The same section constructs a closed sequence template with code $u$. If a total indexed program $P_q$ computes a
function $g$, its specialization with parameter $\NatPair{q}{a}$ has index $s(q,a)$ and computes
$$\begin{aligned}
b_a(n)&:=\begin{cases}
 1,&\KleenePredMax{a}{n}=0,\\
 g(b),&\KleenePredMax{a}{n}=b+1,
 \end{cases}\\
c_a(n)&:=\KleeneSuccIter{b_a(n)}{n+1}.
\end{aligned}$$
The map $\Pair{q}{a}\mapsto s(q,a)$ constructs finite syntax and is total. Apply the self-reference construction to the
closed program computing $3\cdot5^{s(q,a)}$. It supplies a single index $q$ whose total numerical function is
$$g(a):=3\cdot5^{s(q,a)}.$$
This program returns a code without running the sequence it codes. Consequently there is no circular termination
argument: $g$ is total first, and then every $c_a$ is total. The code $s(q,a)$ computes precisely $c_a$
for this same $g$.

Induct along $R$ on $a\in D$, proving simultaneously that $g(a)$ is valid and that for every $k$,
$$\KleeneCandidatePrecedes{\KleeneSuccIter{1}{k}}{g(a)},\qquad
 b\in D,\ bRa\ \Longrightarrow
 \KleeneCandidatePrecedes{\KleeneSuccIter{g(b)}{k}}{g(a)}.$$
Every $b_a(n)$ is valid by the induction hypotheses, so every $c_a(n)$ is valid. If the selected predecessor stays
unchanged, one additional successor operation gives the comparison from $c_a(n)$ to $c_a(n+1)$. If it changes to a
larger predecessor $c$, the induction hypothesis at $c$ places all finite successors of the old base below $g(c)$.
When the old selection was empty, use the assertion about successors of $1$ instead. Append the successors at the new
stage. This proves strict increase in the generated candidate relation, so the limit rule makes $g(a)$ valid.

To prove the two additional assertions at $a$, first use stage $n=k$ for the successors of $1$. If its base is $1$,
one successor step and the limit step suffice; otherwise use the induction hypothesis at the selected predecessor,
then append the successor and limit steps. For $bRa$, choose $n$ larger than both the numerical code $b$ and $k$.
The selected predecessor $c$ is then either $b$ or above it. In the first case the stage supplies more than $k$
successors of $g(b)$; in the second use the induction hypothesis at $c$. Appending the limit step proves the desired
comparison. This completes the simultaneous induction. Since the targets are now valid, these comparisons also hold
in the generated precedence relation on $\KleeneO$.

Write $\rho_W(a)$ for the ordinal position of $a$ in $W$. Another well-founded induction gives
$\rho_W(a)\le\KleeneValue{g(a)}$: for every $bRa$, the induction hypothesis and strict increase give
$\rho_W(b)+1\le\KleeneValue{g(a)}$, and take the supremum over all such $b$.
If $W$ has order type $\alpha$, add a largest element using the recursive successor presentation already constructed.
Its position is $\alpha$, so its assigned notation has value at least $\alpha$. One further successor produces a
notation with value strictly above $\alpha$. The preceding downward-closure proposition supplies a notation of value
exactly $\alpha$. The characterization of recursive ordinals below $\churchKleeneOrd$ gives the last assertion.
\end{proof}

\begin{corollary*}[
\termdefineas{uniform upper notations from decision indices}{Uniform upper notations from decision indices}]
There is a total computable map $\Tuple{d,r,a}\mapsto g(d,r,a)$ with the following property. Let $W=\Pair{D}{R}$ be a
recursive well-order presentation, and let $d,r$ be syntax codes of closed numerical terms deciding its domain
and relation, with output one for true and zero for false. For every $a\in D$,
$$g(d,r,a)\in\KleeneO,\qquad \rho_W(a)\le\KleeneValue{g(d,r,a)}.$$
For every $k\in\NN$,
$$\KleeneCandidatePrecedes{\KleeneSuccIter{1}{k}}{g(d,r,a)}.$$
If $b\in D$ and $bRa$, then also
$$\KleeneCandidatePrecedes{\KleeneSuccIter{g(d,r,b)}{k}}{g(d,r,a)}.$$
The numerical map is total on all triples of natural numbers. The decision and well-order hypotheses guarantee
validity and these comparisons; they are not tested while computing the output.
\end{corollary*}

\begin{proof}[Proof]
§{sec:lambda-recursive-order-programs} gives a total index map $c(d,r)$ for the finite predecessor selector.
From its output, the uniform sequence construction computes a template index $u(c(d,r))$, a self-index
$q(c(d,r))$ and the specialized sequence index $s(c(d,r),a)$. Define
$$g(d,r,a):=3\cdot5^{s(c(d,r),a)}.$$
Composition makes this a total numerical map of the three supplied inputs. Under the decision hypotheses, the
selector computes the finite predecessor maxima for $W$. The sequence program therefore computes exactly the
sequence in the preceding coverage proof, with base values $g(d,r,b)$. Its simultaneous well-founded induction
gives validity and the two candidate comparisons. Its final rank comparison gives the bound on $\rho_W(a)$.
All choices of fixed term representatives are made before the two decision-program indices are supplied.
\end{proof}

The index of the entire upper-notation function is computable from $d,r$ as well. Fix a closed term $H$
computing $\NatPair{\NatPair{d}{r}}{a}\mapsto g(d,r,a)$ and a named representative of $H$ once, and let $h$
be its syntax code. The uniform parameter construction in §{sec:lambda-index-recursion} gives
$$e(d,r):=p\bigl(h,\NatPair{d}{r}\bigr).$$
Then $P_{e(d,r)}$ computes $a\mapsto g(d,r,a)$ for every pair $d,r$, even if they do not describe a well-order.
The preceding corollary supplies validity and the ordinal bounds when the decision hypotheses hold.
Thus later constructions can receive the program index $e(d,r)$ directly, without choosing a new representative
for each presentation.

\begin{theorem*}[\termdefineas{range of Kleene notations}{Range of Kleene notations}]
For every $a\in\KleeneO$, the ordinal $\KleeneValue{a}$ is recursive. Consequently
$$\{\KleeneValue{a}:a\in\KleeneO\}=\{\alpha:\alpha<\churchKleeneOrd\}.$$
\end{theorem*}

\begin{proof}[Proof]
A candidate step need not be decidable, but it has a finite certificate.
§{sec:lambda-certified-descent} constructs a total decision program for a predicate $C(p,\NatPair{b}{c})$
such that
$$\KleeneCandidateStep{b}{p}\quad\Longleftrightarrow\quad
 \exists c\;C(p,\NatPair{b}{c}).$$
For a successor step, check the numerical equality and positivity. For a limit step, the certificate contains an
index, an input, and a bound for the finite beta-certificate test. No test of notation validity is used.

Fix $a\in\KleeneO$. Let $T_a$ contain the empty word and all finite words
$$s=\Tuple{\NatPair{b_0}{c_0},\ldots,\NatPair{b_{k-1}}{c_{k-1}}}$$
whose certificates verify the successive steps starting at $a$: when $k>0$, require
$C(a,\NatPair{b_0}{c_0})$, and require $C(b_i,\NatPair{b_{i+1}}{c_{i+1}})$ for every $i+1<k$.
These finitely many tests decide membership, and every prefix passes the same earlier tests. An infinite branch
would give an infinite candidate descent starting at $a$, contrary to well-foundedness below a valid notation.
Thus $T_a$ is a recursive well-founded tree.

For a node $s$, let $b(s)$ be its last notation, with $b(\emptySeq)=a$. All these notations are valid.
Induction on candidate descent proves that $\KleeneValue{b(s)}$ is at most the strict-extension rank of $s$ in $T_a$.
Indeed, each candidate predecessor $d$ of $b(s)$ has a certificate $c$, and appending $\NatPair{d}{c}$ gives a child.
The induction hypothesis bounds $\KleeneValue{d}$ by the child's rank. Taking successors and then the supremum over
all $d$ proves the assertion at $s$. Certificate choice is used only in this rank comparison, not in the membership
program. At the root this gives $\KleeneValue{a}\le\rho(T_a)$. The recursive Kleene--Brouwer presentation from
§{sec:edst-recursive-tree-ranks} has order type $\beta$ with
$$\KleeneValue{a}\le\rho(T_a)<\beta<\churchKleeneOrd.$$
Downward closure of recursive ordinals shows that $\KleeneValue{a}$ is recursive. The preceding coverage theorem
supplies the other inclusion in the displayed equality.
\end{proof}

\begin{mathmeta}
  \define{EffectiveJoin,IteratedJump}
\end{mathmeta}
For a sequence of sets $A_n\IncludedIn\NN$, its \termdefine{effective join} is
$$\EffectiveJoin{n}{A_n}:=\{\NatPair{n}{m}:m\in A_n\}.$$
We index the iteration by the notation itself. Fix a starting set $A\IncludedIn\NN$.

\begin{proposition*}[\termdefineas{iterated jump along Kleene notations}{Iteration along Kleene notations}]
There is a unique family of sets $\IteratedJump{A}{a}\IncludedIn\NN$, for $a\in\KleeneO$, satisfying
$$\begin{aligned}
\IteratedJump{A}{1}&=A,\\
\IteratedJump{A}{2^a}&=(\IteratedJump{A}{a})',\\
\IteratedJump{A}{3\cdot5^e}&=\EffectiveJoin{n}{\IteratedJump{A}{\varphi_e(n)}}.
\end{aligned}$$
The last two equations apply to permitted successor and limit constructions.
\end{proposition*}

\begin{proof}[Proof]
Generate pairs $\Pair{a}{B}$ by these three rules: start with $\Pair{1}{A}$; from $\Pair{a}{B}$ form $\Pair{2^a}{B'}$;
and, for a permitted limit sequence, join the sets attached to its terms. Induction on the generation of
$a\in\KleeneO$ gives at least one such set $B$. At a limit, choose the sets whose existence is already
established for all sequence terms and take their effective join.

For uniqueness, induct on a derivation of $\Pair{a}{B}$ and compare any other derivation with the same first
coordinate. The three numerical forms are disjoint, and both the successor and limit code functions are
injective. Thus successor derivations have the same preceding notation, where the induction hypothesis
identifies the sets. At a limit, the index $e$ is the same, and uniqueness of the output of $P_e$ identifies
the two numerical sequences term by term. The induction hypotheses identify all their attached sets,
so their joins agree. Assign the unique set to each notation. The rules give the displayed equations;
induction on notation generation shows that any family satisfying them has these same values.
\end{proof}

\begin{proposition*}[\termdefineas{strictness of iterated jumps}{Strict increase along notations}]
If $\KleenePrecedes{a}{b}$, then $\chi_{\IteratedJump{A}{a}}$ is computable relative to
$\chi_{\IteratedJump{A}{b}}$, whereas $\chi_{\IteratedJump{A}{b}}$ is not computable relative to
$\chi_{\IteratedJump{A}{a}}$.
\end{proposition*}

\begin{proof}[Proof]
For a successor step, recover the old set from its jump by the index transformation in
§{sec:lambda-relative-jump}. For a limit step from $\varphi_e(n)$ to $3\cdot5^e$, query the joined
characteristic function at $\NatPair{n}{m}$ to recover the value at $m$ in the $n$th component.
The closed row-reading term and its finite reduction are given in §{sec:lambda-relative-jump}.
For a specified finite precedence chain, substitute these accessors successively into the programs.
The composition theorem gives the forward computation.

For strictness, induct on the generation of $b$. The case $b=1$ has no predecessors. For any chain into
$b$, let $c$ be its last predecessor. Either $a=c$, or the forward computation already proved recovers
the set at $a$ from the set at $c$. A computation of the set at $b$ from the set at $a$ would therefore
compute it from the set at $c$ as well. If $b=2^c$, this contradicts strictness of the ordinary jump.
If $b=3\cdot5^e$, write $c=\varphi_e(n)$ and put $d=\varphi_e(n+1)$. The limit rule gives
$\KleenePrecedes{c}{d}$. The induction hypothesis at $d$ excludes computation of the set at $d$ from
the set at $c$. But the set at $d$ is a component of the join at $b$, so the assumed reverse computation,
followed by its row reader, would do exactly that. This proves strictness also at limits.
\end{proof}

### Witness tables for iterated jumps {#sec:edst-hyperarithmetic-inclusion}

\begin{mathmeta}
  \forward{LambdaNumericProjection}
  \vars{q,x}{Name}
  \vars{b,c,i,m,n}{Nat}
  \vars{f,g}{Fun(Nat,Nat)}
  \vars{G_*}{Name}
  \vars{A,D}{Set(Nat)}
  \vars{a,e,p,v}{Nat}
\end{mathmeta}

A single sequence $q\in\BaireSpace$ can record a domain $D$ and numerical rows $G_b$ by
$$D:=\{b:\LambdaNumericProjection{1}(q(b))=1\},\qquad
 G_b(n):=\LambdaNumericProjection{2}(q(\NatPair{b}{n})).$$
Here numerical projections mean the numerical functions computed by the corresponding closed terms.
Use the decidable certificate predicate $C$ from §{sec:lambda-certified-descent}.
Call $q$ a \termdefine{jump witness table} over $A\IncludedIn\NN$ when the following conditions hold.

1. Every value $G_b(n)$ is zero or one.
2. If $p\in D$ and $C(p,\NatPair{b}{c})$, then $b\in D$.
3. If $1\in D$, then $G_1=\chi_A$.
4. If $b>0$ and $2^b\in D$, then $G_{2^b}(n)=1$ exactly when the closed program $P_n$,
   with input function $G_b$ and numerical argument $n$, returns a numeral in finitely many beta/query steps.
5. If $3\cdot5^e\in D$ and a finite certificate verifies $\varphi_e(i)=b$, then
   $G_{3\cdot5^e}(\NatPair{i}{m})=G_b(m)$ for every $m$.

Write $J_A(q)$ for these conditions. They do not require $D$ to consist of valid notations.
When $A=\emptyset$, the predicate $J_\emptyset(q)$ is arithmetical: every computation in the conditions
has a finite certificate, and only natural-number quantifiers remain.
§{sec:lambda-certified-descent} supplies a total lambda matrix for this assertion.

\begin{lemma*}[\termdefineas{jump witness table uniqueness}{Existence and uniqueness of the required rows}]
For every $A\IncludedIn\NN$ there is a table satisfying $J_A(q)$ whose domain contains all of $\KleeneO$.
For any table satisfying $J_A(q)$ and any $a\in D\cap\KleeneO$,
$$G_a=\chi_{\IteratedJump{A}{a}}.$$
\end{lemma*}

\begin{proof}[Proof]
For existence, take $D=\KleeneO$, put $G_b=\chi_{\IteratedJump{A}{b}}$ on valid rows, and put zero
on all other rows. Validity is downward closed under candidate steps. The iteration equations therefore
verify all five conditions, including every certified output at a limit. Pair the domain bits and the row
values into $q$. This is an existence construction; it does not provide a procedure for deciding validity.

For uniqueness, induct on the generation of $a\in\KleeneO$. The row for the zero notation is prescribed. At a
successor, a certificate for the preceding step places the preceding notation in $D$; the induction
hypothesis identifies its row, and the jump condition determines the new row. At a limit, each value
$\varphi_e(i)$ has a finite output certificate. Downward closure places that notation in $D$, and the
induction hypothesis identifies its row. The fifth condition then determines every entry of the joined
row. Thus all rows needed below a valid $a$ are forced, even if $D$ also contains invalid indices.
\end{proof}

\begin{proposition*}[\termdefineas{uniform lower-jump access}{Uniform access to lower jumps}]
Fix $a\in\KleeneO$. Let $g:\NN\to\NN$ be computed by a total closed numerical lambda term, and suppose
$\KleeneCandidatePrecedes{g(n)}{a}$ for every $n$. There is one closed program, independent of the starting
set $A$, which with input function $\chi_{\IteratedJump{A}{a}}$ returns
$$\chi_{\IteratedJump{A}{g(n)}}(m)$$
on input $\NatPair{n}{m}$. In particular, the entire effective join
$\EffectiveJoin{n}{\IteratedJump{A}{g(n)}}$ is computable from $\IteratedJump{A}{a}$.
\end{proposition*}

\begin{proof}[Proof]
Every candidate edge has a finite certificate. A finite path from $g(n)$ to $a$ therefore has a finite
certificate list. List scanning gives a total checker for such paths with prescribed endpoints.
Search all list codes in numerical order. The precedence hypothesis ensures that the search terminates
for every $n$, so one closed numerical term supplies the path code from $n$.

For a successor edge, use the fixed index map $f$ that recovers a bit from its jump: a query at $m$ in
the lower row becomes a query at $f(m)$ in the upper row. For a certified limit edge at component $i$,
it becomes a query at $\NatPair{i}{m}$. Process the path upward, composing these address changes by
finite numerical recursion. The table equations show at each step that the queried bit is unchanged.
All rows on the path lie in the domain of the canonical table. Its row identities therefore give the
required output after one query to the supplied upper row. The same program handles every $n,m$,
which proves the assertion about the effective join. §{sec:lambda-certified-descent} gives the checker,
search, and address-transforming terms. None of them tests whether a notation is valid.
\end{proof}

\begin{theorem*}[\termdefineas{hyperarithmetic sets are lightface ambiguous}{Hyperarithmetic inclusion}]
Every hyperarithmetic subset of $\NN$ belongs to $\lDelta^1_1$.
\end{theorem*}

\begin{proof}[Proof]
Let $a\in\KleeneO$ and let $P_e$ compute $\chi_B$ from $\chi_{\IteratedJump{\emptyset}{a}}$.
For $v\in\{0,1\}$, the equation $\chi_B(n)=v$ is equivalent to the existence of a table $q$ with
$J_\emptyset(q)$ and $a\in D$, together with a finite beta/query certificate that $P_e$, using row $G_a$,
returns $\ChurchNumeral{v}$ on input $n$. In one direction use the table constructed in the lemma and
termination of $P_e$. In the other, row uniqueness supplies the intended input function, and uniqueness
of numerical output gives the required bit.

The predicate after $\exists q$ is arithmetical. §{sec:lambda-certified-descent} gives a
uniform finite checker for the last certificate as well. The arithmetic pair-tree normal form therefore
gives a recursive tree presentation for each bit. Taking $v=1$ presents $B$ and taking $v=0$ presents
$\SetDifference{\NN}{B}$. For the Baire-space definition of the pointclasses, apply the same construction to
$\{x\in\BaireSpace:x(0)\in B\}$. Hence $B\in\lSigma^1_1\cap\lPi^1_1=\lDelta^1_1$.
\end{proof}

### True Stages and Iterated Approximation {#sec:edst-true-stages}

The ordinal notations and iterated jumps above also support a dynamic approach to effective constructions.
Montalbán's \termdefine{true-stage method} organizes finite approximations to iterated jumps using computable
relations that record which earlier approximations a later stage treats as correct [@Montalban2014].
Coherence between these relations allows a priority construction to coordinate requirements across the
ordinal levels involved.

At a true stage, the relevant finite approximation agrees with the limiting information. The true stages
themselves need not form a computable set: the computable construction follows the relations between finite
stages, and its correctness is proved by analysing what survives along the true stages. This distinction
preserves the difference between approximating higher-level information and computing that information.

Day--Greenberg--Harrison-Trainor--Turetsky [@DayGreenbergHarrisonTrainorTuretsky2024] explain how this machinery
gives new proofs of the Hausdorff--Kuratowski theorem and separation theorems of Louveau and Saint Raymond.
Their classification of Borel Wadge classes [@DayGreenbergHarrisonTrainorTuretsky2025] develops the same method
further, connecting the effective hierarchy here with §{sec:wadge}. These are external applications; the cited
works supply the approximation systems and priority arguments. The present chapters use recursive codes,
ranks, and the Gandy--Harrington topology as their main proof tools.

This completes the hierarchy side of \termuse{effective descriptive set theory}. We now turn from naming the lightface
classes to controlling the ranks and witnesses that make effective versions of classical theorems possible.
